#  AI-Cook Assistant

Умный кулинарный ассистент, который подскажет, что приготовить из того, что есть в холодильнике. Проект использует возможности мультимодальных нейросетей OpenAI для распознавания продуктов и генерации рецептов.

##  Основные возможности

*   **Распознавание продуктов по фото:** Загрузите фотографию холодильника, и модель OpenAI Vision определит список имеющихся продуктов (до 30 позиций).
*   **Умный диалог и память:** Ассистент запоминает предпочтения пользователя (что любит) и жесткие ограничения (аллергии). Все данные хранятся в рамках сессии.
*   **Генерация рецептов:** На основе имеющихся продуктов и профиля пользователя ИИ предлагает 3 варианта блюд. При выборе варианта генерируется полный пошаговый рецепт.
*   **Поиск иллюстраций:** Бэкенд автоматически ищет подходящую фотографию готового блюда через API Wikimedia Commons и возвращает её в формате Base64.
*   **Озвучка текста (TTS):** Встроенный эндпоинт для преобразования текста рецепта в аудио (MP3) с помощью OpenAI TTS.

##  Стек технологий

*   **Язык:** Python 3.10+
*   **Веб-фреймворк:** FastAPI
*   **AI/ML:** OpenAI API (GPT-4o-mini, Vision, TTS)
*   **Работа с сетью:** Requests
*   **Валидация данных:** Pydantic
